<threat_model>
ASVS L1 — read-only presentational change behind the login gate; no new input, action, or secret.
- **Info disclosure via marker:** the glyph only reveals that a session was auto-logged (not
  sensitive) and is derived from a boolean the tutor already owns — no cross-tenant exposure
  (single-user app).
- **Accessibility as correctness:** the marker conveys meaning, so it is labeled (aria-label +
  title) rather than aria-hidden — a decorative-only treatment would be an a11y defect, not a
  security one, but is explicitly avoided per UI-SPEC.
- **XSS:** static lucide SVG + fixed label string; no user-controlled content rendered.
</threat_model>
