## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| student modal → add/editStudentAction | zoomLink crosses as free text; server zod is the sole validator (noValidate form) |
| roster → Gmail compose (new tab) | zoomLink + parent email flow into a URLSearchParams-encoded compose URL; the app never sends |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07 | Tampering (Stored XSS / scheme injection) | zoomLink input | mitigate | Server zod requires an http(s) URL — a `javascript:`/`data:` scheme is rejected before storage; link is only ever placed in a URLSearchParams-encoded mail body, never rendered as an in-app `href` to itself |
| T-04-08 | Tampering (URL param injection) | Gmail compose URL | mitigate | buildGmailComposeUrl uses URLSearchParams (no manual concat) — a `&`/`#` in the link cannot inject params (P3 Pitfall 6) |
| T-04-09 | Information Disclosure | Send button visibility | accept | Behind Phase 1 auth gate; button only exposes the tutor's own student data to the tutor |
| T-04-10 | Spoofing (recipient) | parentEmail as `to` | accept | parentEmail is the tutor-entered, required+unique field (P1 D-13); no external input path |
</threat_model>
