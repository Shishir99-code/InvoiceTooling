| preview form → generateInvoiceAction | Only studentId crosses (unchanged); emailDraft strings are server-rendered from frozen data |
| client → Gmail compose (new tab) | URL built via buildGmailComposeUrl (URLSearchParams-encoded); the app never sends — the tutor sends from her own client |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Tampering (URL/param injection) | Gmail compose URL from subject/body | mitigate | Reuse buildGmailComposeUrl (URLSearchParams — never manual concat), so `&`/`#`/newline in a note or template cannot inject params (P3 Pitfall 6) |
| T-04-04 | Information Disclosure | emailDraft in action return | accept | Contains only the parent email + frozen subject/body the tutor is about to send; behind the Phase 1 auth gate; no new exposure |
| T-04-05 | DoS/UX (orphan tab, over-length garble) | window handle lifecycle | mitigate | Over-length → close handle + copy-first fallback (D-03); error → close handle; blocked/null handle → navigate-only, manual Email button remains (D-04) |
| T-04-06 | Elevation (reverse-tabnabbing) | window.open new tab | mitigate | Redirect an app-opened blank handle only to a trusted mail.google.com URL; no attacker-controlled `opener` on a same-origin blank tab; manual anchors keep rel=noopener |
</threat_model>
