# 07-03: Invoice History UI — Bulk Send Selection & Dialog

**Wave**: 3 (depends on Wave 1; parallel with Wave 2)

**Goal**: Add multi-select checkboxes to invoice history table, show "Send Selected" action button only when ≥1 invoice selected, and implement confirmation dialog before sending.

**Requirements**: BULK-02 (selection UI), BULK-04 (error handling), BULK-05 (verification gate)

## Tasks

### T1: Add selection state to invoice history table component
- File: `components/invoice-history-table.tsx` (update existing)
  - Add React state: `const [selectedInvoiceIds, setSelectedInvoiceIds] = useState<Set<number>>(new Set())`
  - Add checkbox column as first column:
    - Row checkboxes: toggle invoice ID in set
    - Header checkbox: "select all visible unsent invoices" (only unsent ones can be selected; billed ones are read-only or hidden per existing logic)
    - Visual: shadcn/ui Checkbox component
  - Only show checkboxes if `gmailVerified === true` (gated by props; passed from page)
  - If `gmailVerified === false`, show info banner: "Set up email delivery in Settings to send invoices."

**Acceptance**: Can click checkboxes; selected state persists while viewing table. Header checkbox selects all unsent invoices.

---

### T2: Implement "Send Selected" action button & toolbar
- File: `components/invoice-history-table.tsx` (extends T1)
  - Add toolbar above or below table:
    - Text: `"${selectedInvoiceIds.size} invoice(s) selected"`
    - Button: "Send Selected" (primary, disabled if selectedInvoiceIds.size === 0)
    - Button: "Clear Selection" (secondary)
  - Button visible only if `gmailVerified === true` AND `selectedInvoiceIds.size > 0`
  - On click "Send Selected": open confirmation dialog (see T3)

**Acceptance**: Toolbar shows when invoices are selected; "Send Selected" button appears and is clickable.

---

### T3: Confirmation dialog before bulk send
- File: `components/bulk-send-confirmation-dialog.tsx` (new)
  - Props: `{ invoices: Invoice[], isOpen: boolean, onConfirm: () => void, onCancel: () => void, isPending: boolean }`
  - Display:
    - Title: "Send X Invoices?"
    - List of invoices to send (student name, parent email, total amount)
    - Warning: "Emails will be sent from your Gmail account to each parent's email on file."
    - Buttons: "Send" (primary, disabled if isPending), "Cancel"
  - On confirm: call `sendBulkInvoices` Server Action (see Wave 4)

**Acceptance**: Dialog shows invoices to be sent; user can confirm or cancel.

---

### T4: Wire up dialog to table + handle results
- File: `components/invoice-history-table.tsx` (extends T1, T2)
  - Add state: `const [confirmOpen, setConfirmOpen] = useState(false)`
  - Add state: `const [bulkSendResult, setBulkSendResult] = useState<BulkSendResult | null>(null)` (to track success/failure after send)
  - On "Send Selected" click: 
    1. Gather full invoice objects for selectedInvoiceIds
    2. Open confirmation dialog
  - On confirmation: call `sendBulkInvoices(selectedInvoiceIds)` Server Action
  - After send completes:
    1. Show result summary toast: "X sent, Y failed"
    2. Clear selection
    3. Revalidate invoice history to refresh sent/unsent status
    4. If any failed, show detail modal or expandable error list
  - Implement error display: "Failed to send to parent@email.com — Gmail rate limited"

**Acceptance**: Can select invoices, confirm send, and see success/failure toast after completion.
