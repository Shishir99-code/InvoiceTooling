## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → deployed Vercel app | The app is on a public URL; the password gate is the only access control |
| Vercel build/runtime → production secrets | APP_PASSWORD / SESSION_SECRET / DATABASE_URL live in Vercel env, not in the repo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | production secrets in deploy | mitigate | Secrets set in Vercel Environment Variables (Production scope), never committed; `.env.local` gitignored; SESSION_SECRET ≥32 chars, APP_PASSWORD high-entropy. |
| T-05-02 | Tampering | session cookie sent over plaintext HTTP | mitigate | Vercel serves HTTPS; `sessionOptions.cookieOptions.secure` is true in production so the cookie is only transmitted over TLS. |
| T-05-03 | Elevation of Privilege | middleware bypass (CVE-2025-29927) on the deployed app | accept | Next.js 16.2.x (locked) is past the patched threshold (15.2.3); no runtime mitigation needed beyond the deployed version. |
</threat_model>
