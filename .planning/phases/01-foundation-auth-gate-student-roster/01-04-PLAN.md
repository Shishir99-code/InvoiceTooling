## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | irreversible data loss on "remove" | mitigate | Archive sets `archived = true`; the code never issues `DELETE FROM students` (verified by grep gate) — history is preserved and removal is reversible via restore (D-10/D-11). |
| T-04-02 | Tampering | SQL injection / type abuse via student id | mitigate | `id` is coerced to a number and used in a parameterized `eq(students.id, id)` predicate — no raw SQL interpolation. |
| T-04-03 | Elevation of Privilege | unauthenticated archive/restore or archived-view access | mitigate | `/archived` and the actions sit behind the `middleware.ts` gate (Plan 02); unauthenticated requests redirect to `/login`. |
</threat_model>
