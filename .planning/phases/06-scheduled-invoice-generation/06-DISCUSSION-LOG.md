## Cadence config (RINV-01)

| Option | Description | Selected |
|--------|-------------|----------|
| Monthly day-of-month + toggle | Settings on/off toggle + day-of-month; clamp day-past-month-end to last day | ✓ |

## Missed-day behavior (RINV-02)

| Option | Description | Selected |
|--------|-------------|----------|
| Catch up, once per month | Fire on cadence day OR first run after if missed; at most once per calendar month via a monthly HWM | ✓ |
