<threat_model>
ASVS L1 — a single-user, password-gated Settings form.
- **Input validation:** all three cadence fields cross the Server Action boundary and are parsed by
  zod server-side (Task 1) before any DB write — an out-of-range day returns a field error, never a
  raw Postgres error (WR-02 precedent). The client Selects constrain input but are not trusted.
- **Auth surface:** Settings sits behind the existing middleware login gate; no new route or public
  surface is added.
- **No secrets, no external calls, no money computation** in this plan.
- **Regression risk:** the existing upsert fields are preserved verbatim; the new fields are added
  to both insert and update branches so a first-visit insert and a subsequent update both persist
  them consistently.
